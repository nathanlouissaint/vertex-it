# Vertex IT Architecture

## Purpose

Vertex IT is a fictional managed IT, cybersecurity, and cloud services company created as a CloudSight portfolio demonstration.

The objective is to showcase CloudSight's ability to design and develop premium B2B technology websites.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Vercel

## Architecture Principles

- Component-driven development
- Mobile-first responsive design
- Strong accessibility
- High Lighthouse performance
- Minimal unnecessary client-side JavaScript
- Reusable UI primitives
- Conversion-focused page structure
- Clear separation between content, layout, and presentation
